# Kilim Dokuma · Kilim Weaving

Sayılara göre ilmekleri doldur, deseni ortaya çıkar

Satır ve sütun başındaki sayılar, o çizgideki dolu ilmek gruplarının uzunluklarını sırasıyla verir. Kareye dokunarak doldur, boş olduğundan eminsen çarpı modunda işaretle. Desen ayna gibi simetriktir.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Özgün Oyunlar merkez uygulamasının oyunu; ortak motor: [ozgun-motoru](https://github.com/taktemurr-ops/ozgun-motoru).
